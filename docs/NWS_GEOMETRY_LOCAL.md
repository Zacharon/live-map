# NWS missing geography: local candidate

The NWS adapter previously substituted a United States center for alerts without usable geometry. It now retains those alerts with null coordinates, `geographic: false`, `mapDisplayStatus: not-mapped`, and an explanation. Country and area describe provider coverage, not a point. Supported Point, Polygon and MultiPolygon coordinates must have the expected nesting and finite in-range positions; malformed or unsupported geometry remains visible without a pin. Valid points including zero and the existing polygon representative-vertex average retain their prior behavior and raw geometry. This does not claim a true area centroid or change severity, verification, or source-clock policy.

The capability is a public, read-only NWS event projection through the existing `/api/events` response, shared by the normal UI and agent HTTP readers. Inputs are a provider feature and normalization clock; output is the existing event schema with nullable coordinates. There is no user-state mutation, authorization change, new API schema, or external effect. Local synthetic tests exercise normalization, legacy and browser models, map eligibility, detail text, provider fetch and response envelope. Actual browser and keyboard proof, hosted provider behavior, deployment and owner acceptance are NOT RUN. Gates 1–4 have local module/API/render evidence only; gates 5–7 are not applicable to this read-only projection. Independent review remains pending.

Each polygon ring must use consistent 2D or 3D positions, close with the entire first position, contain at least three distinct XY vertices, and have nonzero planar signed area. These minimal shape and degeneracy checks are not full spherical or topological GeoJSON validation: they do not validate self-intersections, hole placement, winding, or antimeridian semantics. Accepted geometry keeps the existing representative-vertex average. Synthetic regression evidence covers the prior H3 examples, collinear and mixed-dimension rings, and closed 3D Polygon and MultiPolygon; independent H3 recheck remains pending.
